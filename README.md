# TC Framework

Password-protected interactive TC framework hosted with GitHub Pages.

The page and its assets are encrypted together with StatiCrypt 3.5.4. The editable source and password are not stored in this repository.

## Versions

- [Original framework](https://mattien1984.github.io/tc-framework/)
- [Fade In](https://mattien1984.github.io/tc-framework/fade-in/): an invisible horizontal cursor control brings complete rings from faded to full opacity.
- [Zoom In](https://mattien1984.github.io/tc-framework/zoom-in/): an invisible horizontal cursor control builds outward in complete rings, starting with a smaller center and pure-white titles.

## Updating

Edit the local working copy, rebuild the encrypted page using the local build script, then push the resulting deployment files. GitHub Pages deploys from the root of the main branch.
